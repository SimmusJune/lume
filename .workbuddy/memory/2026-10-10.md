## 新增「编辑媒体 title / subtitle / tags」能力

需求：媒体资源支持修改标题、副标题、标签（此前全工程只有 create/delete，没有任何 update）。

### 改动文件

- `Lume/Models/MediaModels.swift`：`MediaDetail` 增加 `tags: [String]?`（init 里带默认值 `nil`，加 `CodingKeys`），这样只凭 id 拉一次详情就能拿到编辑所需的三项。
- `Lume/Services/MockStore.swift`
  - `MediaRecord.asMediaDetail()` 补上 `tags`。
  - 新增 `MediaRecord.withEditableFields(title:subtitle:tags:)`：只替换可编辑字段，url / type / 时长 / 封面 / 状态 / 格式原样保留。
  - 新增 `LocalLibraryStore.updateMedia(id:title:subtitle:tags:)`：找不到 id 抛 404；标题走既有的 `buildTitle(_:fallbackURL:)`（留空回退成按 URL 推导的名字，与导入规则一致）；副标题走 `normalizedNonEmpty`；标签走新的 `dedupedTags`（去空白、去空项、按原样去重，全空置 nil）。变更后 `rebuildIndex()` + `refreshFavoriteItems(for:)` + `persist()`，收藏夹里那份冗余副本也会同步。
- `Lume/Services/APIClient.swift`：新增 `didUpdateMedia` 通知 + `updateMedia(...)`。
- `Lume/ViewModels/MediaEditViewModel.swift`（新）：按 id 拉 detail 填充草稿；`parsedTags` 用与导入一致的 `,;|` 分隔；`canSave` 要求标题非空且不在保存中。
- `Lume/Views/MediaEditSheet.swift`（新）：`Form` 三段（Title / Subtitle / Tags）+ 标签 chip 预览（点 chip 删除）。保存成功只负责 dismiss，刷新交给通知。
- `Lume/Views/Components/UIComponents.swift`：`MediaCard` 增加 `onEdit` 回调 + 铅笔按钮。
- `Lume/ViewModels/PlayerViewModel.swift`：新增 `refreshDetailIfNeeded(id:)`，正在播的那首被改名后刷新 `detail`、时长、锁屏信息与 `queueDetails`。
- `Lume/ViewModels/TagPlaylistsViewModel.swift`：`normalizedTags` 改为 `static`；新增 `untaggedGroupName` 常量与 `static belongsToGroup(_:tag:)`，把「Untagged」字面量和成员判定收敛到一处。
- 视图接线：`ExploreView`（列表 + `ExploreTagPlaylistDetailView`）、`TagPlaylistsView`（列表 + `TagPlaylistDetailView`）、`FavoritesListView` 都加了 `editTarget` + 铅笔入口 + `.sheet`，并 `onReceive(didUpdateMedia)` 刷新（两个标签详情页重新拉一遍音频库再按 `belongsToGroup` 重新判定成员，改完标签后会自动进出分组）。`ExploreView` 里把原先写死的删除刷新逻辑抽成 `refreshVisibleSection()`，删除/更新两个通知共用。
- `PlayerView`：标题旁加了铅笔按钮 + `MediaEditSheet` sheet + `onReceive(didUpdateMedia)` 调 `refreshDetailIfNeeded`。

## 追加：tags 支持从已有标签中点选

需求：编辑标签时不想只能手打，要能从曲库里已存在的 tag 里选（避免近义/错拼造出重复分组）。

### 改动

- `Lume/ViewModels/MediaEditViewModel.swift`
  - 新增 `@Published private(set) var availableTags: [String]`。
  - 新增 `fetchAvailableTags()`：`api.fetchMediaList(type: nil, keyword: nil)` 遍历全库（audio + video）收集 tags，trim、去空、去重，按 `localizedCaseInsensitiveCompare` 升序（与 Playlists 的排序一致）。在 `load()` 里用 `async let` 与详情拉取并行。
  - 新增 `isTagSelected(_:)` / `toggleTag(_:)` / `addTag(_:)`；`toggleTag` 已选则移除、未选则追加，都通过重写 `tagsText`（`joined(separator: ", ")`）走既有的 `parsedTags` 解析，保持单一数据源。
- `Lume/Views/MediaEditSheet.swift`
  - 新增 `Section("Existing Tags")`，仅当 `availableTags` 非空时显示；chip 点一下 toggle，已选用 `Color(hex: "9dff85")` 填充 + checkmark（与 `ChipView` 选中色一致），未选用 `Color.secondary.opacity(0.18)`。
  - 新增 `private struct TagFlowLayout: Layout`：自动换行的流式布局（`LazyVGrid` 会强行等宽不适合芯片）。`sizeThatFits` 在 proposal 有界时返回满宽、否则返回最宽行。
  - footer 文案更新为「comma 分隔或从已有标签里挑」。

### 验证

- 全工程 `swiftc -typecheck`：**0 error**。
- `xcodebuild ... build`：**BUILD SUCCEEDED**，0 error。产物 `.build-dd` 已清理。
- `TagFlowLayout.sizeThatFits` 的数学抽成等价纯函数实跑 6 组用例（单个/一行/恰好换行/边界等于 maxWidth/超宽单 chip/5 个折行）全绿。

## 追加：改成 token 式输入（推翻上一版的「独立 Existing Tags 栏」）

反馈：不要单独一栏 chip，要**在 tags 输入区里点一下就能下拉选已有标签，也能自己输新的**。

### 改动（重写这两个文件）

- `Lume/ViewModels/MediaEditViewModel.swift`
  - `tagsText: String` → 拆成 `tags: [String]`（已选，唯一数据源）+ `tagInput: String`（草稿）。`parsedTags` 改名 `static parseTags(_:)`。
  - 新增 `pendingTags` / `creatableTags` / `canCreateFromInput` / `matchingTags`（私有）/ `suggestions`（最多 8 条）/ `hasMoreSuggestions`。
  - 匹配与去重统一改成**忽略大小写**（`caseInsensitiveCompare` / `lowercased()`），避免 `Rock` 和 `rock` 并存。
  - 新增 `updateTagInput(_:)`：写入同时若含 `,;|` 就立刻 commit。
  - `save()` 先 `commitTagInput()`，防止「输入框敲了标签没回车直接点保存」丢内容。
- `Lume/Views/MediaEditSheet.swift`
  - 删掉独立的 `Section("Existing Tags")` 和 `Section("Preview")`；改成单一 `Section("Tags")`：内联已选 chip + `TextField` + 建议行 + `Create “xxx”` 行（用 `@FocusState` 控制是否展开下拉）。
  - 建议行/show 条件：`isTagFieldFocused || !tagInput.isEmpty`。
  - footer 说明文案 + 建议被截断时提示「Keep typing to narrow the list」。

### 踩坑（重要）

`.onChange(of:) { _, newValue in }` 双参数版**需要 iOS 17，而工程 `IPHONEOS_DEPLOYMENT_TARGET = 16.0`**。我的类型检查命令之前写的是 `-target arm64-apple-ios17.0-simulator`，把它掩盖了 —— 类型检查 0 error，`xcodebuild` 才报 `'onChange(of:initial:_:)' is only available in iOS 17.0 or newer`。
改法：TextField 绑到自定义 `Binding` 的 setter（`viewModel.updateTagInput($0)`），完全不依赖 `onChange`。同时把记忆里的类型检查命令目标改成 `ios16.0`。
