- 需求：重启 App 后保留上次的播放模式（顺序 / 单曲循环 / 随机）。
- 改动文件：`Lume/ViewModels/PlayerViewModel.swift`

  - 新增 `@AppStorage("lume.playMode") private var storedPlayMode = PlayMode.sequential.rawValue`。
  - `init` 中读取该 key 恢复 `playMode`。
- 现状说明（未改动）：队列 / 上次曲目 / 播放来源（favorites·playlist·library）已持久化；播放倍速 `rate`、播放进度 `positionSeconds` 仍未持久化（进度只通过 `postProgress` 上报服务端，重启从 0 开始）。
- 保留 `@Published` + didSet 而非改成计算属性，是为了保证 SwiftUI 能收到 `objectWillChange` 刷新图标。
